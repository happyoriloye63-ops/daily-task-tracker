# Daily Task Tracker

## Project Overview

Daily Task Tracker is a proposed application designed to help students organize their daily activities. It is intended to provide one place where students can record tasks, keep track of pending activities, and monitor completed work.

The project aims to address common problems such as forgetting important activities, finding it difficult to decide what to do first, and losing track of completed tasks. The application has not been built yet.

## Objectives

- Help students organize their daily responsibilities.
- Make it easier to identify tasks that are still pending.
- Allow students to monitor the tasks they have completed.
- Encourage better planning and time management.

## Proposed Features

The following features are planned for the application:

1. **Add tasks:** Students will be able to enter new activities.
2. **Edit tasks:** Students will be able to change task details.
3. **Mark tasks as completed:** Students will be able to update a task's status.
4. **Delete tasks:** Students will be able to remove tasks they no longer need.
5. **View tasks:** Students will be able to view pending and completed tasks.

## Proposed Installation and Setup

Once the project has been created and its files are available, a developer is expected to follow these planned steps:

1. Obtain the project files from the project's GitHub repository or another provided source.
2. Open the `daily-task-tracker` folder in Visual Studio Code.
3. Check that the expected HTML, CSS, and JavaScript files are present.
4. Open the project in a web browser, using the development method selected for the project.

**Note:** These are planned setup instructions. They have not yet been tested because the application and its files have not been implemented.

## Expected Usage

When the application is developed, a student is expected to:

1. Open Daily Task Tracker in a web browser.
2. Add activities they need to complete during the day.
3. Edit a task if its details change.
4. Mark a task as completed after finishing it.
5. View pending tasks to see what still needs attention.
6. Delete tasks that are no longer needed.

These steps describe the intended use of the proposed application, not features that are currently available.
